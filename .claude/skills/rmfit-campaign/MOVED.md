# rmfit-campaign skill: lives with rmfit

The `rmfit-campaign` skill, the process guide for rmfit's global R-matrix
fitting campaigns, is kept with the code it describes:

    rmfit/.claude/skills/rmfit-campaign/SKILL.md

To use it in Claude Code, link or copy that directory to
`~/.claude/skills/rmfit-campaign` (or to `.claude/skills/rmfit-campaign` of the
project you work in). Edit it under `rmfit/`, not here.

This file is deliberately not named SKILL.md, so that a session started at the
top of this repository does not load a second skill called `rmfit-campaign`.

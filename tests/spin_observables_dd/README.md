# spin_observables_dd — isDiff 9 on identical spin-1 bosons (d + d)

Nineteen spin observables of a d + d toy (identical bosons: only l + s even; levels 0+, 2+ with
s- and l-mixing, 1-, 2-, 0-, 3-): vector and spherical-tensor analyzing powers of beam and target
(`b:y`, `t:y`, `b:iT11`, `b:T20/21/22`, `t:T20/21/22`), Cartesian tensor powers (`b:yy`, `b:xx`,
`b:zz`, `b:xz`), spin correlations including tensor x tensor (`b:y*t:y`, `b:x*t:x`, `b:z*t:z`,
`b:yy*t:yy`), outgoing polarization (`e1:y`) and transfer (`b:y>e1:y`).

As in `spin_observables_p3He`, the data are an independent calculation (here with the identical-
particle symmetrization: nuclear pathways x (1 + (-1)^(l'+s')), Coulomb f_C(th) + (-1)^s f_C(pi - th))
plus an alternating +-0.01 offset with errors 0.01, so chi2/N = 1.0000 per segment records agreement
(1e-7). Beam and target observables of identical particles come out equal, as they must.

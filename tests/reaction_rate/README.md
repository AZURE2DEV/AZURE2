# reaction_rate — N_A<σv> from mode 5 equals the integral of the extrapolated cross section

The reaction rate (`ReactionRate.cpp`, CLI mode 5) is checked against the same model's cross
section from a dense mode-3 extrapolation, integrated independently (`truth.py`, trapezoid on a
grid with steps of 1 % of E in every decade and 1 eV across the narrow level). Mode 3 never
touches `ReactionRate.cpp`, so the reference is independent of the code under test; it is stored
in `expected/rates_*.dat` and regenerated by `make_truth.sh`.

The models (`make_models.py` (deleted; see "How the models were made"), from `tests/13N/13N.azr` with external capture off, no data and
no target effects):

| model | what | case |
|---|---|---|
| p12C | p + 12C capture: the Gamow tail of the 1/2+ 2.37 MeV level and the others | (a) |
| n12C | the same levels with a neutron entrance (z1 = 0, m1 = 1.008665, the 13C gamma pair): sigma ~ 1/v from the s-wave 1/2+ level | (b) |
| moved | p12C plus a 1/2+ level at E_x = 2.0935 MeV, Γp = 20 eV (s-wave, 4 % of the Wigner limit), Γγ = 2 eV | (d) with `expected/moved.par` |
| moved_azr | the same level at 2.0985 MeV in the .azr; its `param.par` is `expected/moved.par` | the truth of (d), and (e) |

`check.sh` runs mode 5 on the temperatures of `temperatures.dat` (T9 = 0.01, 0.03, 0.1, 0.3, 1)
and checks every temperature to 1e-3:

**One path (2026-11-12).** The cases (c) and (h) ran n12C and p12C_2g through the per-temperature
quadrature, which the `<config>` key `useAdaptiveGrid=0` selected; the key was removed, and the rate
always takes the tabulated path.  The quadrature stays as the fallback for a grid with fewer than
three points of sigma > 0 (an exit closed almost everywhere below 50 MeV).  Case (c) reaches it with
`p12C_closed`: p12C with a third pair, p + 12C in a fictitious state at 48 MeV (an ANC of 0.5 fm^-1/2
on the 1/2+ background level at 20 MeV), which opens at E_cm = 48 MeV, between the grid's last two
backbone nodes, so that only the node at 50 MeV has sigma > 0.  No physical model of this suite
reaches the fallback: only an exit that opens within the top 2.3 MeV of the rate's range (a residual
state some 46 MeV above the entrance threshold) does, so the input is contrived.  Its truth
(`expected/rates_p12C_closed.dat`, T9 = 2 to 10, `temperatures_closed.dat`) is the dense mode-3
extrapolation of pair 3 that `closed_truth.py` adds to the model, integrated by `truth.py`; the rate
agrees to the 6 printed digits.

**Total radiative capture (2026-11-04).** The exit key `-1` ("Total capture (all γ pairs)" in the
GUI's Run tab) makes the rate integrate the sum of the capture cross sections into every capture pair
of the entrance pair's compound nucleus. `p12C_2g` (`make_models.py` (deleted; see "How the models were made")) is p12C with a second capture
pair, key 3, to a fictitious bound 3/2- state of 13N at E_x = 1.0 MeV (every pair-2 gamma line copied
with 0.6 x the width).

**What it caught (2026-10-25 audit, items F1, F2, F3, F6 of `03_rmatrix_core.md`; fixed
2026-10-26).**

- (a) The tabulated path splined sigma itself against E on a 48-per-decade backbone. Below
  the barrier sigma changes by a factor 2-3 between nodes and a monotone spline of convex data
  lies below it. Now ln sigma against ln E, where a 1/v cross section is a straight line and a
  Gamow tail nearly one.
- (b) sigma was set to zero below 1 keV on both paths. For a neutron entrance the integrand
  sqrt(E) exp(-E/kT) has half its weight there at T9 = 0.01. The range now starts at 0.1 eV,
  where an s-wave neutron rate at T9 = 0.01 is complete to 1e-6; a charged entrance underflows to
  sigma = 0 long before.
- (d), (e) The resonance clusters of the sigma grid and the quadrature breakpoints were placed
  at the .azr level energies after TransformIn (formal values under --no-brune), not at the
  parameters being evaluated. A 22 eV level moved by 5 keV in a parameter file fell between
  the 7 keV backbone nodes and the rate lost it. Now the resonances come from the parameters
  (a clone transformed out and refilled with the observed values, as the target-effect sub-grids
  do in `WorkingCopy::ReplaceSubPointGrids`).
- The Boltzmann constant was 8.6171e-2 MeV/GK; CODATA 2018 is 8.617333262e-2 (the rate of a
  narrow resonance moves by E_r/kT x 2.7e-5, 0.1-0.3 %). The truth uses CODATA throughout.
- Found while building the test: `gsl_integration_qagp` over E with breakpoints at a resonance's
  +-8 widths stopped 3e-4 short of its request on the smooth neutron integrand and 5e-4 on the
  narrow level. The quadratures now run over ln E; the spline path uses every knot as a
  breakpoint (the integrand between knots is a cubic in ln sigma times E^2 exp(-E/kT), which
  Gauss-Kronrod integrates to rounding), the direct path brackets each resonance out to 1024
  widths.

Regenerating the reference (`./make_truth.sh path/to/AZURE2`) needs only mode 3 and python3;
the dense extrapolations take a few seconds. The 4 eV window first used across the 22 eV level
left the trapezoid 6e-4 off, 1 eV reproduces a 0.5 eV, +-40 keV window to 1e-7.

## How the models were made

The committed models are the reference.  They were written by `make_models.py` in the old project format and converted
to format 3 with `tools/format3_tree_convert.sh` (`AZURE2 --convert ... --to 3 --exact-grids`); the generator
was deleted with the old format (it is in the repository's history: `git show 123c747c:tests/reaction_rate/make_models.py`).  To change a
model, edit its records.  The generator's description of what it wrote:

```text
Models for tests/reaction_rate, derived from tests/13N/13N.azr (p + 12C capture).

Every model has external capture off (EC mask 0 on the gamma lines), no data segments and
every <targetInt> line inactive, so mode 3 (extrapolation) and mode 5 (rate) run in a second
or two on the R-matrix part alone.

  p12C        charged entrance, as 13N:  the Gamow tail of the 1/2+ 2.37 MeV level and the
              others (audit F1: the spline of sigma against E lay 0.77 % low at T9 = 0.01).
  n12C        the same levels with a neutron entrance (z1 = 0, m1 = 1.008665): sigma ~ 1/v
              from the s-wave 1/2+ level (audit F2: sigma = 0 below 1 keV lost 49 % at T9 = 0.01).
  p12C_2g     p12C with a second capture pair (key 3) to a fictitious bound 3/2- state of 13N at
              E_x = 1.0 MeV: every pair-2 gamma line copied with the final state 3/2- and 0.6 x the
              width (all the multipolarities stay allowed into 3/2-).  The total radiative capture
              rate (exit key -1) must be the sum of the rates into pairs 2 and 3.
  moved       p12C plus a narrow 1/2+ level (Gamma_p = 20 eV s-wave, Gamma_gamma = 2 eV, Gamma = 22 eV) at
              E_x = 2.0935 MeV (E_cm = 0.150 MeV).  moved_azr has it at 2.0985 MeV instead
              (+5 keV = 250 widths); its parameter file is used on moved.azr, so the parameters
              being evaluated put the resonance 5 keV from the .azr value (audit F3: the grid
              clusters followed the .azr value and the resonance fell between backbone nodes).

The truth extrapolation segments (<segmentsTest>, mode 3) are written into the *_truth.azr
copies only: decade segments with a step of 1 % of the decade's low end, and for the narrow
level a 1 eV (c.m.) window of +-20 keV around the resonance (4 eV, 5.5 points per width, was
6e-4 off).

    python3 make_models.py            # writes models/*.azr
```

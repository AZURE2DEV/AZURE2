# reaction_rate — N_A<σv> from mode 5 equals the integral of the extrapolated cross section

The reaction rate (`ReactionRate.cpp`, CLI mode 5) is checked against the same model's cross
section from a dense mode-3 extrapolation, integrated independently (`truth.py`, trapezoid on a
grid with steps of 1 % of E in every decade and 1 eV across the narrow level). Mode 3 never
touches `ReactionRate.cpp`, so the reference is independent of the code under test; it is stored
in `expected/rates_*.dat` and regenerated by `make_truth.sh`.

The models (`make_models.py`, from `tests/13N/13N.azr` with external capture off, no data and
no target effects):

| model | what | case |
|---|---|---|
| p12C | p + 12C capture: the Gamow tail of the 1/2+ 2.37 MeV level and the others | (a) |
| n12C | the same levels with a neutron entrance (z1 = 0, m1 = 1.008665, the 13C gamma pair): sigma ~ 1/v from the s-wave 1/2+ level | (b), and (c) with `useAdaptiveGrid=0` |
| moved | p12C plus a 1/2+ level at E_x = 2.0935 MeV, Γp = 20 eV (s-wave, 4 % of the Wigner limit), Γγ = 2 eV | (d) with `expected/moved.par` |
| moved_azr | the same level at 2.0985 MeV in the .azr; its `param.par` is `expected/moved.par` | the truth of (d), and (e) |

`check.sh` runs mode 5 on the temperatures of `temperatures.dat` (T9 = 0.01, 0.03, 0.1, 0.3, 1)
and checks every temperature to 1e-3:

| | check | old build (dev 3dcb1ea) | fixed |
|---|---|---|---|
| (a) | p12C against the truth | 0.84 % low at T9 = 0.01 | 2e-5 |
| (b) | n12C against the truth | 49.6 % low at T9 = 0.01, 2.8 % at 0.1 | 5e-6 |
| (c) | n12C through the per-temperature quadrature (`useAdaptiveGrid=0`) | 48.7 % low | 5e-6 |
| (d) | moved with the parameter file of moved_azr against the truth of moved_azr | 99.6 % low at T9 = 0.1 to 1 | 1e-4 |
| (e) | moved_azr (no parameter file) equals (d) to 1e-9 | differs by 230x | equal |

**What it caught (2026-10-25 audit, items F1, F2, F3, F6 of `03_rmatrix_core.md`; fixed
2026-10-26).**

- (a) The tabulated path splined sigma itself against E on a 48-per-decade backbone. Below
  the barrier sigma changes by a factor 2-3 between nodes and a monotone spline of convex data
  lies below it. Now ln sigma against ln E, where a 1/v cross section is a straight line and a
  Gamow tail nearly one.
- (b), (c) sigma was set to zero below 1 keV on both paths. For a neutron entrance the integrand
  sqrt(E) exp(-E/kT) has half its weight there at T9 = 0.01. The range now starts at 0.1 eV,
  where an s-wave neutron rate at T9 = 0.01 is complete to 1e-6; a charged entrance underflows to
  sigma = 0 long before.
- (d), (e) The resonance clusters of the sigma grid and the quadrature breakpoints were placed
  at the .azr level energies after TransformIn (formal values under --no-brune), not at the
  parameters being evaluated. A 22 eV level moved by 5 keV in a parameter file fell between
  the 7 keV backbone nodes and the rate lost it. Now the resonances come from the parameters
  (a clone transformed out and refilled with the observed values, as the target-effect sub-grids
  do in `EData::ReplaceSubPointGrids`).
- The Boltzmann constant was 8.6171e-2 MeV/GK; CODATA 2018 is 8.617333262e-2 (the rate of a
  narrow resonance moves by E_r/kT x 2.7e-5, 0.1-0.3 %). The truth uses CODATA throughout.
- Found while building the test: `gsl_integration_qagp` over E with breakpoints at a resonance's
  +-8 widths stopped 3e-4 short of its request on the smooth neutron integrand and 5e-4 on the
  narrow level. The quadratures now run over ln E; the spline path uses every knot as a
  breakpoint (the integrand between knots is a cubic in ln sigma times E^2 exp(-E/kT), which
  Gauss-Kronrod integrates to rounding), the direct path brackets each resonance out to 1024
  widths.

Regenerating the reference (`./make_truth.sh path/to/AZURE2`) needs only mode 3 and python3;
the dense extrapolations take a few seconds. The 4 eV window first used across the 22 eV level
left the trapezoid 6e-4 off, 1 eV reproduces a 0.5 eV, +-40 keV window to 1e-7.

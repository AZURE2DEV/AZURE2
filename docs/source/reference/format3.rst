Project format 3: the table
===========================

Schema version ``3.0``.  A format-3 project describes each data set, target, beam, detector, shared normalization, energy scale, extrapolation and model datum as one record: a header line ``<kind> <name>`` followed by one ``<key> <value>`` line per field, inside the section that holds the kind.  ``#`` starts a comment; a token with blanks is quoted; indentation is not significant.  Every closed choice below is a row of one table compiled into the engine; ``AZURE2 --schema`` prints it as JSON and ``pyazr.schema()`` returns it as a dict.  ``AZURE2 --validate FILE`` (``pyazr.validate(path)``) checks a project against it and reports every problem; ``AZURE2 --convert OLD NEW`` (``pyazr.convert_azr(old, new)``) writes an older project in this format (:doc:`../user_guide/older_projects`).  The design is ``docs/upgrade/project_format3.md``.

Names are ``[A-Za-z][A-Za-z0-9_-]*`` and unique across the project; a field names another record by its name.  Within a section, record kinds and field keys are disjoint, so a line is a header or a field by its first word.

     - a <config> key format 3 does not have, a <config> line after the eleven entries that is not key=value, or a line of <mcmc> outside <parameters>: nothing would read it
   * - ``E_CONFIG_OPTION_VALUE``
     - error
     - an option of the calculation in <config> (use_brune, transform, ...) with a value other than 0, 1, true or false
   * - ``E_CONFIG_OPTIONS_CONTRADICT``
     - error
     - two options of the calculation that cannot hold together, whatever gave them: a flag, a keyword, a <config> key or the default (use_park=1 with use_brune=0, use_rmc=1 with use_brune=1, ec_convection_current=0 with use_long_wavelength=1)
   * - ``E_PARAMETER_FILE_NO_MATCH``
     - error
     - a parameter file (param.sav as a run's start) none of whose names is a parameter of the run
   * - ``W_PARAMETER_FILE_NAMES``
     - warning
     - a parameter file with names the project has no parameter for, or without names of parameters it has
   * - ``W_PARAMETER_SETTING_UNKNOWN``
     - warning
     - a <parameterSettings> row that names no parameter of the project (ignored)
   * - ``E_SO_TWO_SPINS``
     - error
     - a spin-orbit term on a pair whose two particles both have spin (the coupled treatment is not implemented)
   * - ``E_SO_ZERO_SPIN``
     - error
     - a spin-orbit term acting on a particle of spin 0 (it would vanish)
   * - ``E_SO_RELATIVISTIC``
     - error
     - a spin-orbit term in a project with relativistic kinematics
   * - ``E_SO_THM``
     - error
     - a THM data set or extrapolation whose entrance pair's potential has a spin-orbit term
   * - ``E_SO_NEEDS_J``
     - error
     - channel functions of a pair with a spin-orbit term asked for without J (pyazr, the API)
   * - ``E_SO_NO_TERM``
     - error
     - channel functions of a pair without a spin-orbit term asked for with a J (pyazr, the API)
   * - ``W_NOT_MEASURABLE``
     - warning
     - a data set of a quantity that is computed for tests and comparison, not measured
   * - ``W_BROAD_LEVEL``
     - warning
     - a resonance strength of a level with Gamma / E_r > 1 %: eq. (8) and the area of the resonance differ
   * - ``W_NEARBY_LEVEL``
     - warning
     - a resonance strength of a level with another level of its J^pi within 10 Gamma
   * - ``W_DATA_FILE_NOT_READ``
     - warning
     - a data file that cannot be read in a run that does not use the data (an extrapolation): not read
